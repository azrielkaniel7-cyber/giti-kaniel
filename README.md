# אתר גיטי קניאל - גרסה 2 (מואר ויוקרתי)

אתר סטטי (HTML + CSS + JS), עברית RTL, רספונסיבי. פותחים `index.html` בדפדפן.

## כל התוכן נערך בקובץ אחד: `content.js`
- **המלצות**: מוסיפים בלוק ל-`testimonials`.
- **פרויקטים**: בלוק ב-`projects` (כותרת, קטגוריה `done`/`wip`, תיאור, `cover` ו-`gallery` לתמונות). הפרויקטים הקיימים הם דוגמאות.
- **מאמרים**: בלוק ב-`articles` (כותרת, תקציר, וסעיפים `{h, p}`). לכל מאמר נוצר עמוד אוטומטית.
- **סרטונים**: `videos`. יוטיוב: `{type:"youtube", id:"<המזהה מהקישור>"}`. אינסטגרם: `{type:"instagram", id:"<המזהה מ-/reel/...>"}`. הסרטון נטען רק בלחיצה, כדי שהאתר יישאר מהיר.
- **אינסטגרם / יוטיוב של העסק**: ממלאים ב-`social`. ריק = לא מוצג.

## תמונות
שמים ב-`images\` ורושמים את הנתיב ב-`content.js`. עד שיש תמונה מוצג משטח רך. תמונה ראשית לדף הבית: `images\hero.jpg`. תמונת גיטי: `images\giti.jpg`.

## קבצים
`index` בית · `projects` + `project?id=` · `blog` + `article?id=` · `about` · `contact`.
העיצוב והצבעים ב-`style.css` (משתנים ב-`:root`). הפונטים: Frank Ruhl Libre (כותרות) ו-Heebo (טקסט).
